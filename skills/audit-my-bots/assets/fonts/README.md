# Bundled fonts

All four families are licensed under the SIL Open Font License 1.1 (license texts in this folder; also kept in each file's name table).
They were subset to Latin plus the 2,350 common Hangul syllables (KS X 1001) and renamed, as the OFL requires for modified
versions when a Reserved Font Name exists ("Plex"). `tools/presubset_fonts.py` documents how.
